## 🔄 ПОТОК ДАННЫХ (архитектура)

```
DOMContentLoaded (chess.html)
    ├─ checkAuth()
    │   ├─ Читает userData из localStorage
    │   ├─ Парсит JSON
    │   └─ Вызывает updateUI()
    │
    ├─ updateUI() (script.js)
    │   ├─ Проверяет наличие userData
    │   ├─ Обновляет профиль (имя, elo, энергия)
    │   ├─ Показывает VIP-бейдж (если is_premium)
    │   ├─ Создает кнопку админки (если role == 'admin')
    │   ├─ Вызывает checkPremiumSettings()
    │   └─ Логирует все действия
    │
    ├─ checkPremiumSettings() (script.js)
    │   ├─ Показывает/скрывает #premium-settings
    │   ├─ Устанавливает энергию (∞ для VIP)
    │   ├─ Применяет Premium-тему
    │   └─ Логирует изменения
    │
    ├─ initStockfish() (script.js)
    │   └─ Один раз инициализирует движок
    │
    ├─ showTab() (script.js)
    │   └─ Восстанавливает последнюю вкладку
    │
    └─ showNotification() (script.js)
        └─ Показывает приветственное сообщение
```
