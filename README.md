# Dosan Project

Frontend және Backend үйрену барысында жасалатын толық жоба.

## Жоба туралы
Қазір жоба бастапқы кезеңде. Болашақта толыққанды fullstack қосымшаға айналады.

## Қолданылатын технологиялар

### Қазір
- Next.js
- React
- TypeScript
- Tailwind CSS

### Болашақта жоспарлануда
- Дерекқор: PostgreSQL / MongoDB
- ORM: Prisma
- Аутентификация (тіркелу, кіру)
- REST API
- Deploy: Vercel

## Құрылым
- `src/app` — беттер және API маршруттары
- `src/components` — UI компоненттері
- `src/lib` — көмекші функциялар
- `src/types` — TypeScript типтері

## Қалай іске қосу
npm install
npm run dev

Содан кейін http://localhost:3000 ашыңыз.
