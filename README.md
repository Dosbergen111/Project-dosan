# Habit Tracker

Күнделікті әдеттерді бақылауға арналған fullstack веб-қосымша. Frontend және Backend үйрену барысында жасалуда.

## Жоба туралы
Пайдаланушы өз әдеттерін қосып, күн сайын орындалғанын белгілейді. Қосымша қатарынан орындалған күндерді (streak) және статистиканы есептеп көрсетеді.

## Негізгі мүмкіндіктер
- Әдет қосу, өзгерту, өшіру
- Күн сайын орындалды деп белгілеу
- Streak (қатарынан неше күн) есептеу
- Күнтізбелік карта және апталық, айлық статистика
- Тіркелу және жеке кабинет
- Достармен челлендж (кейін)

## Қолданылатын технологиялар

### Қазір
- Next.js
- React
- TypeScript
- Tailwind CSS

### Болашақта жоспарлануда
- Дерекқор: SQLite, кейін PostgreSQL
- ORM: Prisma
- Аутентификация (тіркелу, кіру)
- REST API
- Deploy: Vercel

## Құрылым
- `docs` — техникалық тапсырма және құжаттама
- `src/app` — беттер және API маршруттары
- `src/components` — UI компоненттері
- `src/lib` — көмекші функциялар, дерекқор
- `src/types` — TypeScript типтері

## Қалай іске қосу
```bash
npm install
npm run dev
```

Содан кейін http://localhost:3000 ашыңыз.
