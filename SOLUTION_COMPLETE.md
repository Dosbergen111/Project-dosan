───────────────────────────────────────────────────────────────────────────────

✅ Добавлен в server.js

   ПАРАМЕТРЫ ЗАПРОСА:
   {
       userId: число,
       username: строка,
       plan: 'month' | 'quarter' | 'lifetime',
       price: число
   }
   
   ЛОГИКА ОБРАБОТКИ:
   1. Валидация входных данных
   2. Подключение к БД
   3. UPDATE Users SET is_premium = 1 WHERE id = @id
   4. Также обновляет energy = 5
   5. Возвращает обновленного пользователя
   
   ОТВЕТ СЕРВЕРА:
   {
       "success": true,
       "message": "Премиум активирован!",
       "user": {
           "id": число,
           "username": "ник",
           "elo": число,
           "energy": 5,
           "role": "user",
           "is_blocked": 0,
           "is_premium": 1,
           "last_energy_update": дата-время
       },
       "plan": "month|quarter|lifetime"
   }
   
   ОБРАБОТКА ОШИБОК:
   • 400 Bad Request: отсутствуют параметры
   • 404 Not Found: пользователь не найден
   • 500 Server Error: ошибка БД с подробностями
