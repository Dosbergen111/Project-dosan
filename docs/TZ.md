# Техникалық тапсырма: Habit Tracker

## 1. Жалпы мәлімет
- **Жоба атауы:** Habit Tracker
- **Түрі:** Fullstack веб-қосымша
- **Мақсаты:** Frontend және Backend бағыты бойынша білімді практикада бекіту

## 2. Жобаның мақсаты
Пайдаланушы күнделікті әдеттерін қосып, орындалуын белгілеп, прогресін (streak, статистика) көріп отыратын қосымша жасау.

## 3. Мақсатты аудитория
Жаңа әдеттер қалыптастырғысы келетін студенттер мен жұмыс істейтін адамдар.

## 4. Функционалдық талаптар

### 4.1. Негізгі (1-кезең)
- Әдет қосу (атауы, сипаттамасы, жиілігі)
- Әдеттер тізімін көру
- Әдетті өзгерту және өшіру
- Күн сайын әдетті "орындалды" деп белгілеу (және белгіні алып тастау)
- Streak есептеу (қатарынан неше күн орындалды)

### 4.2. Кеңейтілген (2-кезең)
- Күнтізбелік карта (орындалған күндер жасыл түспен)
- Апталық және айлық статистика
- Әдеттерді категорияға бөлу
- Мақсат қою (аптасына неше рет)

### 4.3. Қосымша (3-кезең)
- Тіркелу және жүйеге кіру
- Әр пайдаланушының өз деректері
- Достармен челлендж және рейтинг
- Интернетке шығару (deploy)

## 5. Функционалды емес талаптар
- Бет 3 секундтан аз уақытта ашылуы керек
- Интерфейс телефон мен компьютерде дұрыс көрінуі (адаптивті дизайн)
- Енгізілетін деректер тексерілуі (валидация)
- Код TypeScript-пен жазылуы, құрылымы түсінікті болуы
- Құпия сөз қауіпсіз түрде (хэштелген) сақталуы (3-кезең)

## 6. Технологиялар
| Бөлік | Технология |
|---|---|
| Frontend | Next.js (App Router), React, TypeScript, Tailwind CSS |
| Backend | Next.js API Routes |
| Дерекқор | SQLite, кейін PostgreSQL |
| ORM | Prisma |
| Аутентификация | (3-кезең) |
| Deploy | Vercel |
| Нұсқаларды басқару | Git, GitHub |

## 7. Деректер моделі

**Habit** (әдет)
| Өріс | Түрі | Сипаттама |
|---|---|---|
| id | Int | Бірегей нөмір |
| name | String | Әдет атауы |
| description | String | Сипаттамасы |
| category | String | Категория |
| goalPerWeek | Int | Аптасына мақсат (рет) |
| createdAt | Date | Құрылған күні |

**HabitLog** (орындалу белгісі)
| Өріс | Түрі | Сипаттама |
|---|---|---|
| id | Int | Бірегей нөмір |
| habitId | Int | Қай әдетке жатады |
| date | Date | Орындалған күні |

**User** (3-кезең): id, email, password, name

Байланыс: бір әдетте көп HabitLog болады (бір-көп).

## 8. API
| Әдіс | Жол | Әрекет |
|---|---|---|
| GET | /api/habits | Барлық әдеттерді алу |
| POST | /api/habits | Жаңа әдет қосу |
| PUT | /api/habits/[id] | Әдетті өзгерту |
| DELETE | /api/habits/[id] | Әдетті өшіру |
| POST | /api/habits/[id]/log | Күнді орындалды деп белгілеу |
| DELETE | /api/habits/[id]/log | Белгіні алып тастау |
| GET | /api/stats | Статистика және streak (2-кезең) |

## 9. Интерфейс беттері
- **Басты бет:** бүгінгі әдеттер тізімі, орындалды деп белгілеу түймесі, streak
- **Әдеттер беті:** барлық әдеттер, қосу, өзгерту, өшіру
- **Статистика беті:** күнтізбелік карта, графиктер (2-кезең)
- **Кіру / Тіркелу беттері** (3-кезең)

## 10. Жұмыс кезеңдері
1. Жоба құрылымын дайындау, README және ТЗ жазу
2. Типтер мен frontend (жалған деректермен)
3. API жазу
4. Дерекқорды қосу (Prisma + SQLite)
5. Frontend пен API-ды байланыстыру
6. Streak есептеу, статистика, күнтізбелік карта
7. Тіркелу және кіру
8. Deploy

## 11. Қабылдау критерийлері
- Әдетті қосу, өзгерту, өшіру қателіксіз жұмыс істейді
- Күнді белгілеу және белгіні алу дұрыс сақталады
- Streak дұрыс есептеледі
- Деректер бет жаңартылғанда жоғалмайды
- Код GitHub-та, README-де іске қосу нұсқаулығы бар
